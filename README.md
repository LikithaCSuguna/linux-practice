# Linux Bash Practice

A collection of Linux and Bash scripting solutions created as part of my placement preparation. This repository covers fundamental Bash concepts through hands-on coding exercises and HackerRank practice problems.

## Topics Covered

* Linux Commands
* Input & Output
* Variables
* Arithmetic Operations
* Conditional Statements
* Loops
* Bash Scripting Basics

## Solutions Included

| File                                       | Description                                                                          |
| ------------------------------------------ | ------------------------------------------------------------------------------------ |
| `00. Linux-cheatsheet.md`                  | Frequently used Linux and Bash commands for quick reference.                         |
| `01. Let's Echo.sh`                        | Prints the string **HELLO**.                                                         |
| `02. welcome.sh`                           | Reads a user's name and prints a welcome message.                                    |
| `03. odd-numbers.sh`                       | Prints all odd numbers from **1** to **99**.                                         |
| `04. arithmetic-operations.sh`             | Performs addition, subtraction, multiplication, and integer division.                |
| `05. comparing-numbers.sh`                 | Compares two integers and displays the appropriate result.                           |
| `06. getting-started-with-conditionals.sh` | Uses conditional statements to print **YES** or **NO** based on the input character. |
| `07. triangle-type.sh`                     | Determines whether a triangle is **Equilateral**, **Isosceles**, or **Scalene**.     |

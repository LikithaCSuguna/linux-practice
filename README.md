## Solutions Included

| #  | File                                                       | Description                                                                             |
| -- | ---------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| 00 | `00. Linux-cheatsheet.md`                                  | Frequently used Linux and Bash commands for quick reference.                            |
| 01 | `01. Let's Echo.sh`                                        | Prints the string **HELLO**.                                                            |
| 02 | `02. welcome.sh`                                           | Reads a user's name and prints a welcome message.                                       |
| 03 | `03. odd-numbers.sh`                                       | Prints all odd numbers from **1** to **99**.                                            |
| 04 | `04. arithmetic-operations.sh`                             | Performs addition, subtraction, multiplication, and integer division.                   |
| 05 | `05. comparing-numbers.sh`                                 | Compares two integers and displays the appropriate result.                              |
| 06 | `06. getting-started-with-conditionals.sh`                 | Uses conditional statements to print **YES** or **NO** based on the input character.    |
| 07 | `07. triangle-type.sh`                                     | Determines whether a triangle is **Equilateral**, **Isosceles**, or **Scalene**.        |
| 08 | `08. looping-with-numbers.sh`                              | Prints the natural numbers from **1 to 50**.                                            |
| 09 | `09. arithmetic-expressions.sh`                            | Evaluates arithmetic expressions and prints the result rounded to **3 decimal places**. |
| 10 | `10. compute-the-average.sh`                               | Calculates the average of given integers and prints it rounded to **3 decimal places**. |
| 11 | `11. head-of-text-file-1.sh`                               | Displays the first **20 lines** of the input.                                           |
| 12 | `12. head-of-text-file-2.sh`                               | Displays the first **20 characters** of the input.                                      |
| 13 | `13. middle-of-text-file.sh`                               | Displays lines **12 through 22** of the input.                                          |
| 14 | `14. tail-of-text-file-1.sh`                               | Displays the last **20 lines** of the input.                                            |
| 15 | `15. Slice an Array.sh`                                    | Reads an array and displays a specified slice of its elements.                          |
| 16 | `16. Display an Array.sh`                                  | Reads an array and displays all its elements separated by spaces.                       |
| 17 | `17. Filter an Array with Patterns.sh`                     | Filters out array elements containing the letters **a** or **A**.                       |
| 18 | `18. Concatenate an Array with Itself.sh`                  | Concatenates an array with itself twice and displays the resulting array.               |
| 19 | `19. Display an Element of an Array.sh`                    | Displays the element at index **3** of the array.                                       |
| 20 | `20. Count the Number of Elements in an Array.sh`          | Counts and displays the number of elements in an array.                                 |
| 21 | `21. Remove the First Capital Letter from Each Element.sh` | Replaces the first capital letter in each array element with a dot.                     |

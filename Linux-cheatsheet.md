# Linux & Bash Commands

## Create a Directory

```bash
mkdir Bash-Practice
```

## Move into Directory

```bash
cd Bash-Practice
```

## Create a Bash Script

```bash
touch hello.sh
```

## Open in Nano

```bash
nano hello.sh
```

## Basic Bash Script

```bash
#!/bin/bash

echo "HELLO"
```

## Make Script Executable

```bash
chmod +x hello.sh
```

## Run Script

```bash
./hello.sh
```

## Check Current Directory

```bash
pwd
```

## List Files

```bash
ls
```

## List All Files (including hidden)

```bash
ls -la
```

## Copy a File

```bash
cp hello.sh hello-copy.sh
```

## Rename a File

```bash
mv hello.sh hello-world.sh
```

## Delete a File

```bash
rm hello.sh
```

## Delete a Folder

```bash
rm -r Bash-Practice
```

## Create Multiple Files

```bash
touch file1.sh file2.sh file3.sh
```

## Print Working Directory

```bash
pwd
```

## Clear Terminal

```bash
clear
```

## Display File Contents

```bash
cat hello.sh
```

## Search Text

```bash
grep "echo" hello.sh
```

## File Permissions

```bash
ls -l
```

## Change Permissions

```bash
chmod +x hello.sh
```
